# LR VAE roundtrip：独立图像观察

结论：这两条已被检查过的 dev 问题片段中，在完全不调用 upscaler 的低分辨率 VAE 往返路径，已能重现明显的人脸形变和大运动轮廓/拖影错误。普通 2× 下采样再 bicubic 放大主要增加模糊，没有出现同等程度的结构变化；HR384 VAE 往返重建更接近 raw source384。

这支持把低分辨率 VAE 往返链路作为独立损伤来源继续排查，不能单独归因 encoder，也不证明 latent 中的信息全部不可恢复。不能据此排除 upscaler/因果化额外引入损伤，不能把两条事后挑选的 dev 片段推广到整个数据集。

实际查看：两张原 JPEG 2688×2060 的完整五时刻四列 contact sheet（frame14/17/19/22/60；查看工具显示缩至1794×1375）及从原 PNG 不缩放裁出的三时刻局部图（frame17/19/60）。四列顺序均为 raw source384、raw LR bicubic、LR VAE roundtrip bicubic、HR384 VAE roundtrip。JPEG仅观察，以下指标取原始未压缩RGB生成的 summary.json。

- Horse 0421364：原片本身已有运动模糊，应与额外重建损伤区分。第三列 frame19 腹下/腿部增加横向拖影和轮廓错位；frame22 腿部轮廓及马头、骑手细节明显破损；frame60 马腿、鞍具、阴影形状进一步偏离。第二列较模糊但总体姿态保持，第四列显著更接近第一列。
- Player 0665341：第三列 frame17/19 的眼鼻口出现重复错位及形状变化；frame22/60 嘴部、鼻颊形变尤为明显，发丝及手/琴弦也变模糊。第二列主要为分辨率下降，第四列面部结构明显更接近原图。
