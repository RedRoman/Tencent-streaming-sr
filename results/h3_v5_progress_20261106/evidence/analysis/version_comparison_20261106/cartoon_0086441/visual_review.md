# 0086441 同帧可视检查

实际查看六格合成视频的第 0、17、60、90、119 帧，并查看早期50步/当前和双向teacher/当前的原尺寸双栏帧。另提取19、22帧但未在本轮逐张查看。5条视频均通过全120帧技术解码审计；这不等于逐帧主观画质通过。

观察：零更新aligned、50步、旧eWarp已有额外重复细线与轮廓，尤其猴子眼睛、帽沿、篮子和女孩挥手位置。v5/motion减少不少细线，背景/服装呈现更平滑的质感；猴子眼部等主要错形仍然明显。motion与v5非常接近，没有从这些帧看到主要问题解决。原版双向teacher也有共同损伤，不能把它与零更新因果改造混称。

因此该片支持“训练改变并平滑纹理、主要形变没有解决”，不支持简单断言“未训练版本原本干净，所有伪影均由微调产生”。这是已观看测试片上的事后观察，不是盲测结论。低清VAE往返两dev的损伤证据属于另一个诊断，不能当作本片的直接测试结果。
